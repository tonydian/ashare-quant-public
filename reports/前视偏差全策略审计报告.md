# 前视偏差（look-ahead）全策略审计报告

> 2026-10-25；起因：板块轮动发现"同 bar 前视"导致回测虚高 249 倍，
> 系统性排查**所有策略**是否有同类问题。
> **结论：主策略、宽基 ETF、板块轮动三个生产策略均无此 bug；仅有 1 个研究脚本曾存在，已修复。**

## 1. 实测证据（不只看代码）

### 1.1 主策略：2017 笔交易逐笔验证成交价

用「成交价 vs 当日开盘价 / 当日收盘价 / 前日收盘价」三者对比：

| 匹配对象 | 笔数 | 占比 |
|---|---:|---:|
| **当日开盘价** | **2017** | **100.0%** |
| 当日收盘价 | 0 | 0% |
| 前日收盘价 | 0 | 0% |

**100% 的成交都是当日开盘价**，且第一笔交易出现在 2020-01-09（信号日 2020-01-08 的次日）。

→ **主策略使用「次日开盘价」成交，时序完全正确。**

### 1.2 宽基 ETF：注入前视做对照实验

| 版本 | CAGR | Sharpe | MaxDD |
|---|---:|---:|---:|
| **当前实现（T+1 正确）** | **10.57%** | **0.912** | -10.74% |
| 人为注入同 bar 前视 | **63.40%** | 4.781 | -4.79% |
| **虚高幅度** | **+52.83pp** | | |

→ 如果宽基 ETF 有前视，结果会是 63.40% 而不是 10.57%。**当前实现是干净的。**

### 1.3 板块轮动：修正前后对比

| 版本 | CAGR | Sharpe | MaxDD |
|---|---:|---:|---:|
| 修复前（同 bar 前视） | 32.09% | 1.468 | -20.41% |
| **修复后（严格 T+1）** | **13.68%** | **0.680** | -25.78% |
| **虚高幅度** | **+18.41pp** | | |

### 1.4 研究脚本 v3：修复后与生产版一致

| 版本 | CAGR | Sharpe |
|---|---:|---:|
| 修复前（同 bar） | 34.72% | 1.529 |
| **修复后（T+1）** | **13.93%** | 0.691 |
| 生产版 `qf/sector_rotation.py` | 13.68% | 0.680 |

→ 两者差异仅 0.25pp（来自参数与池子细节），**口径已统一**。

## 2. 为什么"组合类脚本"结构上不可能有前视

`three_strategy_combo.py` 和 `etf_combo_50_50.py` 的检查结果：

| 检查项 | 结果 |
|---|---|
| 使用价格数组（`close[` / `open[` / `price[`） | **False** |
| 使用成交逻辑（`buy_` / `sell_` / `order` / `shares`） | **False** |

它们只是**对已有净值序列做加权求和**：
```python
combo_ret = sum(rets[k] * w for k, w in weights.items())
```
只要成分净值本身没有前视，组合同样没有。

## 3. 间接检验：调仓日收益 vs 非调仓日收益

前视的典型症状是"调仓当天就赚钱"（因为买了当天已经涨的）。实测：

| 策略 | 调仓日均值 | 非调仓日均值 | 差 |
|---|---:|---:|---:|
| 主策略 | +0.0655% | +0.0321% | +0.0334pp |
| 板块轮动 | +0.0857% | +0.0417% | +0.0440pp |

**差异都在 0.05pp 以内**，属于正常噪声范围（调仓日往往伴随趋势突破，本身收益略高是合理的）。
如果存在同 bar 前视，这个差异会是 **0.5pp 以上**量级。

## 4. 三个策略的前视影响幅度对比（重要）

| 策略 | 正确 CAGR | 若有前视 | 虚高幅度 | 对前视的敏感度 |
|---|---:|---:|---:|---|
| 宽基 ETF | 10.57% | 63.40% | **+52.83pp** | **极高** |
| 板块轮动 | 13.68% | 32.09% | +18.41pp | 高 |
| 主策略（个股） | 8.77% | 未知（不适用） | — | 低（10日调仓，且用开盘价） |

**规律：越是"突破类"策略（买当下正在涨的），对同 bar 前视越敏感。**
因为突破日当天往往大涨，能不能用当天收盘价买到，差异巨大。

这也解释了为什么板块轮动的 bug 影响那么大——它买的正是"今天创新高"的标的。

## 7. 给未来的检查清单（防复发）

任何新策略回测，必须验证这 4 条：

1. **成交价语义**：打印成交记录，确认 `成交价 == 目标日开盘价`（而非信号日收盘价）
2. **首笔交易日期**：必须晚于首个信号日至少 1 天
3. **注入前视测试**：人为改成同 bar，看结果是否暴涨（>10pp 说明策略对前视敏感，需格外小心）
4. **CAGR 合理性**：A 股单策略年化 > 50% 先怀疑代码，不要先高兴

## 9. 最终答案

**"这个 bug 其他策略会有吗？"**

| 策略 | 答案 |
|---|---|
| 主策略（个股） | **不会有**。100% 用次日开盘价，实测 2017 笔全部正确 |
| 宽基 ETF 趋势 | **不会有**。若真有前视，CAGR 会是 63% 而不是 10.57% |
| 板块轮动（生产版） | **曾有过，上轮已修**（32.09% → 13.68%） |
| 板块轮动（研究版 v3） | **有过，本轮刚修**（34.72% → 13.93%） |
| 三策略组合 / ETF 50/50 | **不可能有**（纯加权，不涉及成交） |

**唯一需要警惕的教训**：越是"买当下领涨标的"的策略，对同 bar 前视越敏感。
以后新增这类策略，必须做「注入前视」对照实验。
