## 2. bug：预算归一化把仓位系数吃掉了

`latest_target.csv` 里的金额**已经乘过 regime**（破位时 0.45）。旧代码：

```python
base  = df["target_value"].sum()      # ≈ 0.45 × 本金
scale = main_alloc / base             # 0.50 × 本金 / (0.45 × 本金) = 1.111
```

缩放回 50% 预算，恰好把 0.45 除掉 —— 主策略腿又变成满仓。

| | 股票敞口 | 说明 |
|---|---:|---|
| 回测 50/50（regime 0.45） | **22.5%** | 另一条腿 ETF 当期为 0，其余在国债 |
| 修前实盘 combo | **49.97%** | `main.allocated = 149,921` |
| 修后实盘 combo（四腿） | **47.8%** | 主 17.96% + 低换手 29.83%，与理论值 0.40×0.45+0.30 = 48% 一致 |

> 这是**实盘比回测激进一倍多**的问题，而且是静默的：没有任何阶段报错，
> `−6.93%` 的回撤因此是打了折的数字。

修法两处（第二处容易漏）：

```python
main_cap = main_alloc * invested_pct          # 腿真正要投的钱
scale    = main_cap / base
...
if used + p["lot_px"] > main_cap:             # 补余量的上限也必须改
```

如果只改 `scale` 不改补余量上限，`for p in sorted(plan, key=-drop)` 那一步
会把腿重新填回 `main_alloc`，**bug 从后门回来**。

### 2.1 用不变量而不是数值来钉住

`tests/test_combo_signal.py::test_combo_main_keeps_regime`：

```python
combo.main.allocated / capital / weights.main  ==  latest_signal.json.invested_pct   (±2%)
```

它比的是「组合里的投入比例」与「主策略信号自己的投入比例」——
以后改预算（0.4→0.5）、改 regime 阈值、改持仓数都不会误报，只有真的把系数吞掉才会红。

## 3. 执行损耗：等额腿白扔了 8%

低换手腿 10 只 × 9,000 元，旧代码 `int(9000/lot)*lot`：

| 标的 | 价格 | 旧股数 | 旧金额 | 缺口 |
|---|---:|---:|---:|---:|
| 中国人寿 | 35.79 | 200 | 7,159 | −1,841 |
| 天新药业 | 24.83 | 300 | 7,450 | −1,550 |
| … | | | | |
| **合计** | | | **82,631** | **−7,369（8.2%）** |

新函数 `_size_equal_legs()`：向下取整后把余量补回**缺口最大**的标的，
但单只最多超配 +10%（避免为填坑把某只买成 1.2 倍）。
低换手腿从预算的 **91.8% → 99.4%**，回收 6,862 元。

超配上限是刻意的：宁可留 1,000 元现金，也不要让「等权 10 只」变成「某只 1.19 倍」。

## 3.1 同一个病：ETF 腿实盘比回测激进一倍

回测（`scripts/etf_trend_strategy.py`）写得很清楚：

```python
MAX_POS   = 2          # 最多同时持 2 只
POS_STYLE = "equal"    # 每只固定 1/2；只有 1 只突破时自动降到半仓
```

而实盘 `_etf_trend_signal()` 只取**第 1 个突破的标的**，并按**整腿预算**买满。
两者在「只有 1 只突破」时差 2 倍 —— 而 ETF 腿 90% 的时间都是这种状态（平均暴露约 15%）。

现在改为 `_size_etf_leg(picks, budget)`：最多 2 只、每只固定 `budget/2`。
两个测试钉住（`test_etf_leg_uses_half_budget_each` / `test_etf_leg_max_two`）。
当前三只宽基 ETF 均未突破，所以今天金额不变（0），但下次突破时不会再买成双倍。

## 4. 四腿口径：为什么是这个权重

来自 `reports/四条腿组合层与有效边界_2026-11-05.md`（共同区间 2020-01-08 ~ 2026-10-23）：

| 方案 | CAGR | σ | Sharpe | MaxDD | OOS CAGR | OOS SR |
|---|---:|---:|---:|---:|---:|---:|
| 旧 50/50 | 7.62% | 6.78% | 0.895 | −6.93% | 5.37% | 0.566 |
| **40/30/20/10** | **9.00%** | 7.74% | **0.958** | −7.25% | **6.97%** | **0.721** |

- 全期 +1.38pp 收益、+0.063 Sharpe，换了 +0.96pp 波动和 +0.32pp 回撤；
- **样本外是更干净的一档**：+1.60pp 收益、+0.155 Sharpe，回撤只深 0.32pp；
- 它已经贴在有效边界上（距前沿最优点仅 **0.05pp**），**不做权重优化**
  （val 段最优 Sharpe 1.900 → OOS 0.538，比不优化还差）。
