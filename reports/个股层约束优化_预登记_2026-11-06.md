# 个股层约束优化 —— 预登记（2026-11-06）

> **本文件在任何实验运行之前写定。跑完之后不允许修改判据；若事后放宽必须显式标注
> 「事后放宽」并说明原因。**

## 1. 要回答的问题

主策略的收益来自「短周期反转 + 低波 + 低换手 + 价值」这一个 alpha 源，多头端天花板
约 8.50%（见 `reports/因子层优化三条路证伪_2026-11-05.md`）。因子层已被三轮证伪，
因此本次**不动因子、不动分数、不动模型**，只改**同一个分数如何变成持仓**。

具体问：现在这套「按分数排序 → 贪心等权 → 单行业 ≤25% 绝对上限」的组合构建，
是否让组合在**行业**和**风格**上承担了与 alpha 无关的押注？把这两类押注设上限，
能否在**不牺牲收益**的前提下降低回撤、提高 Sharpe？

## 2. 变量（三个变体，互不重叠）

| 代号 | 改动 | 说明 |
|---|---|---|
| **BASE** | 无（现状） | `qf/portfolio.build_target`，单行业 ≤25%、双创 ≤50%、单票 2%~8%、缓冲区 2.0、新进 6 只 |
| **A** | 加「行业**相对**基准偏离 ≤ ±3pp」 | 现状只有绝对上限 25%，等于允许「整个组合压在两个行业上」。A 改为对齐基准行业结构 |
| **B** | 加「风格暴露上限」 | SIZE / VOL / MOM / LIQ 单边 \|E\| ≤ 1.0 sd，VALUE 双向 \|E\| ≤ 0.5 sd（z 单位，组合加权平均） |
| **C** | A + B | 同时加 |

风格定义沿用 `qf/attribution.py: build_styles`（SIZE=ln市值、VALUE=0.5·z(EP)+0.5·z(BP)、
MOM=60日动量跳5日、VOL=60日收益标准差、LIQ=20日成交额/市值），**自建、PIT、无外部数据**。

基准口径：`md.eligible[t]` 等权（与组合等权构建一致），不用市值加权。

> 设计说明：B 的阈值刻意设成「限制过度押注」而不是「完全中性化」。当前模型是**故意**
> 买低波小盘（88% 权重在买冷清），把 SIZE/VOL 拉到 0 等于把 alpha 一起扔掉。所以预登记
> 的是上限而非归零——这一点在跑之前就定死，避免看到结果再调参数。

## 3. 判据（采纳需**全部**满足）

1. **全期 Sharpe**（2020-01 至数据末）≥ BASE + **0.05**
2. **全期 MaxDD** 优于 BASE ≥ **1.0pp**
3. **分段一致性**：`20-21` / `22-23` / `24-26` 三段中，至少 **2 段**的 CAGR 不低于
   BASE − 0.50pp（允许单段小幅落后，不允许靠一段撑全场）
4. **相位一致性**：8 个调仓相位（offset 0~7 个交易日）中，至少 **6 个**的 Sharpe ≥ BASE
5. **换手约束**：年化换手 ≤ BASE × **1.20**（约束优化不应靠加交易换体验）
6. **成本稳健**：滑点 15 / 25 / 40 / 60 / 80bp 五档，方向与判据 1 一致（不出现
   「低滑点赢、高滑点输」的翻转）

任一不满足 → 判定**证伪**，生产参数不动。

## 4. 多重检验记账

- `N_trials = 3`（A / B / C 三个变体，BASE 为基准不计入）
- 不做「三个里挑最好那个」的隐性挑选：三个变体的结果必须**全部**出现在报告里，
  包括失败的两个。只有预登记判据全过的变体才可提交采纳。
- 本次不引入新因子，因此不涉及因子层的 FDR / DSR 校正；但组合层参数（3pp、1.0sd、
  0.5sd）本身是超参数，故**判据 3+4 就是防过拟合的那道闸**，不接受事后调参重跑。

## 5. 明确不做的事

- 不改 `qf/model.py`、不改 `build/models/wf_h10` 的分数
- 不改 `qf/portfolio.py` 的生产路径（新逻辑写在新模块，生产默认不启用）
- 不碰转债腿、ETF 腿、主腿权重（那是另一件事，见 `reports/转债四腿有效边界_2026-11-05.md`）
- 不用 MCP 拉 Barra 风格因子（byte_limit 下全历史拉取不可行，见下方附注）

## 6. 数据通道附注

`pandadata` 的 12 个 Barra 风格因子在 MCP 通道单次只回约 3.5 万字节（单日全市场 268 行），
做 2016-2026 × 5000 股的面板需数千次调用，**不可行**。故本次风格暴露用项目自建的 5 风格。
那 4 个真正空白的 Barra 因子（earnings_quality / earnings_variability / investment_quality /
growth）留给 SDK 通道，不在本次范围。
