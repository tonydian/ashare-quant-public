## 三、⚠️ 关键发现 1：RSI<50 买入是负贡献

### 3.1 对照实验（OOS 期）

| 买入条件 | 卖出条件 | OOS CAGR |
|---|---|---:|
| **RSI<50（你的规则）** | RSI>70 | **-6.08%** |
| RSI<50 | 无卖出 | +4.38% |
| **不限制** | **RSI>70** | **+6.01%** ⭐ |
| 不限制 | 无卖出 | +4.38% |
| RSI>50（反向） | RSI>70 | +4.18% |
| RSI>50（反向） | 无卖出 | +4.18% |

**结论：**
- **"RSI<50 才买" = -12.09pp 拖累**（-6.08% → +6.01%）
- **"RSI>70 卖" = 正贡献**（+4.38% → +6.01%）

### 3.2 为什么 RSI<50 买入是错的

**池内股票的 RSI 分布（2050 个样本）：**

| 分位 | RSI14 |
|---|---:|
| 5% | 28.5 |
| 25% | 40.2 |
| **50%（中位）** | **48.0** |
| 75% | 56.0 |
| 95% | 68.8 |

- RSI < 50 的比例：**58.4%**
- RSI > 70 的比例：**3.9%**

**问题在于：**
```
"RSI<50 才买" 的真实效果 =
  在股票已经下跌时买入（接飞刀）
  A股小盘股下跌后往往继续跌（动量延续）
  → 买到的是"正在崩的股票"

"RSI>70 卖" 是有效的 =
  超买时卖出，锁定利润
  → 这是正确的止盈
```

**讽刺的是：如果改成"RSI>50 买"，OOS 从 -6.08% 变成 +4.18%（+10.3pp）。**

**但最优是"完全不限制买入"（+6.01%）。​**

## 四、⚠️ 关键发现 2：基本面筛选在 OOS 是负贡献

### 4.1 剥离测试

| 配置 | DEV | OOS |
|---|---:|---:|
| **纯小市值前 10**（无基本面） | 8.15% | **13.40%** |
| **基本面 + 小市值** | **13.96%** | 6.01% |
| **基本面增量** | **+5.81pp** | **-7.39pp** |

**这是最反直觉的结果：**
- **DEV 期：基本面筛选 +5.81pp（有效）**
- **OOS 期：基本面筛选 -7.39pp（有害）**

### 4.2 为什么

**纯小市值在 OOS 表现好（13.40%），是因为 2022-2026 是小盘股行情（微盘股指数大涨）。**

**而基本面筛选（ROE>15%、净利>20%、PB<10）把"高估值高增长的微盘股"筛掉了，反而错过了微盘行情。​**

**这印证了我之前的判断：基本面因子在 A 股小盘股上不稳定。**

## 八、我建议的处理

### 方案 1：保留策略但去掉 RSI 买入限制

```
基本面（稳健版）+ RSI>70 止盈（不限制买入）
OOS 6.01%, MaxDD -31.18%
```

**这是当前最好且能解释的版本。**

### 方案 2：加防御机制

**2023 年 -27.42% 的问题是"小盘崩盘时无防御"。**

**改进**：加一条"市场择时"——当沪深300 跌破 MA200 时，降到半仓或持有国债。

### 方案 3：接受"这策略不如主策略"

**对比：**

| 策略 | OOS/全期 CAGR | MaxDD | 值得用吗 |
|---|---:|---:|---|
| **主策略（40日）** | **6.21%** | **-12.46%** | ✅ 回撤小得多 |
| **基本面 RSI（当前）** | 6.01%（OOS） | **-31.18%** | 🟡 回撤大 2.5 倍 |

**同样 6% 收益，主策略回撤只有 12%，这个策略是 31%。**

**风险调整后主策略明显更优（Calmar 0.50 vs 0.19）。**

## 九、我的最终建议

| 优先级 | 建议 |
|---|---|
| **1** | **不要用原版**（0 只候选，无法运行） |
| **2** | 稳健版可以跑，但 **RSI<50 买入必须去掉** |
| **3** | 即使改进后，**不如主策略**（同收益但回撤 2.5 倍） |
