# 统计显著性校正报告（backtest-guard 中 1 / 中 2 项）

> 生成时间 2026-10-23；数据 2016-10-14 ~ 2026-10-14（原始包，与主回测同源）。
> 只做统计口径校正，不改变现行主策略（详见 §3 结论与 §4 建议）。

## 1. 标签重叠校正（🟡 中 1）

**问题**：周频行步长 5 个交易日，h10 标签跨 11 个交易日 → 相邻 IC 样本重叠
`(11-5)/11 = 54.5%`，朴素 t 统计量被高估。

| 口径 | 复合分 IC 显著性 |
|---|---|
| 朴素 t（n=326 周） | **14.28** |
| Newey-West t（Bartlett, lag=2） | **10.97** |
| 有效样本折算 t（n_eff = 326×5/10 = 163） | **10.10** |
| 循环块 bootstrap 95% CI（mean IC） | **[0.0680, 0.0970]** |

策略日收益（`build/runs/main`，2020-01-08~2026-10-14）：

| 口径 | 值 |
|---|---|
| 年化 Sharpe | 0.733 |
| 朴素 t（Sharpe×√years） | 1.87 |
| 日收益均值 Newey-West t（lag=5） | 2.27 |
| Sharpe block bootstrap 95% CI（block=21 日，2000 次） | **[0.001, 1.522]** |

**解读**：
- IC 的显著性在重叠校正后仍很强（t≈10~11，95% CI 不含 0）→ **选股能力在统计上是成立的**，
  不是 14.28 那么夸张，但也不是噪声。
- **策略 Sharpe 的置信区间 [0.00, 1.52] 极宽** → 6.5 年样本对 Sharpe 的估计精度很低，
  不应把 0.73 当成稳定预期；这与"年化 t 仅 1.87"一致。
- 结论：IC 层面 robust，**收益层面的不确定性远大于 IC 层面**（因为 Sharpe 受制于
  少数几段行情 + 择时 overlay 的路径依赖）。

## 2. 多重筛选校正（🟡 中 2）

### 2.1 800 候选的 BH-FDR（选池实际口径：5 日 DEV ICIR）

| 口径 | 显著因子数 |
|---|---|
| 800 候选中 BH-FDR(q=0.05) 判显著 | **126 / 800（15.8%）** |
| 单侧 5% 未校正的期望假阳性 | 约 40 个 |
| q=0.10 | 194 / 800 |

→ 校正后仍有 126 个因子显著，说明**因子库整体信号密度较高**，但远非"800 个都有效"。

### 2.2 现行 34 因子池 vs BH-FDR 显著集

- **落在显著集内的只有 23 个**；**11 个不显著却入池**（靠族配额/相关性剪枝进来）：
  `momentum-extra:M001 / M005 / M008`、`directional:R600 / R729 / R732 / R733 / R762`、
  `volume-stat:R626 / R758`、`risk-pattern:R473`。
- 注意 `momentum-extra` 三个因子**全部**不显著——它们是我们自行补充的"中期反转族"，
  在 5 日 DEV 口径下未通过多重检验。

### 2.3 敏感性实验：只保留 BH-FDR 显著因子（23 个）

| 版本 | CAGR | Sharpe | MaxDD | Calmar | 交易 |
|---|---:|---:|---:|---:|---:|
| 现行池（34，含 11 个不显著） | **8.77%** | **0.733** | **-10.62%** | **0.83** | 2017 |
| 仅 BH-FDR 显著池（23） | 7.15% | 0.629 | -13.29% | 0.54 | 1985 |
| 差异 | **-1.61pp** | -0.104 | -2.67pp | -0.29 | |

**⚠️ 这个结果必须诚实解读**：剔除"统计不显著"的因子后，**策略明显变差**（-1.6pp 年化）。
原因有三：
1. 这 11 个因子是**组合层面有用但单因子不显著**（低相关、分散化价值）——多重检验看的是
   "单因子是否真有效"，而组合收益来自"多个弱信号的互补"；
2. DEV 期（147 周）样本短，BH-FDR 对**弱但真实**的因子过于严格（功效不足），
   会误杀；320 个 5 日 DEV 观测下，ICIR≈0.1 的因子很难单独显著；
3. 现行的 |ICIR| 排序 + 族配额 + 相关性剪枝本身就是为了"组合多样性"，
   与"逐个因子做显著性检验"是两套目标。

### 2.4 更严格的口径：在 h10 DEV 标签下重做（与模型一致）

- DEV(h10) 有效因子 224 个（受限于趋势/基本面族只覆盖 475 周行中的一部分），
  BH-FDR(q=0.05) 显著 **196 个**；现行 34 个池因子**全部**落在显著集内。
- 用这 196 个显著因子直接重训（不设池上限）：CAGR **8.34%** / Sharpe 0.703 / MaxDD -11.32%
  → 与现行 8.77% 接近但略差（池过大 + 弱因子被纳入）。

### 2.5 结论

| 问题 | 答案 |
|---|---|
| 800→34 是否存在严重假阳性？ | **不严重**：34 个里有 23 个通过 BH-FDR；11 个不显著的多为"组合互补型弱因子" |
| 是否应该改成"只保留显著因子"？ | **不建议**：实测会让收益从 8.77% 降到 7.15%，回撤恶化 |
| 正确做法 | ① 在报告中**披露**这 11 个因子未通过 BH-FDR；② 保留组合（分散化价值）；③ 把 BH-FDR 作为**监测/告警**而非硬性筛选 |

## 4. 建议

1. **保留现行 34 因子池**（实测更优），但在回测报告与体检报告中**披露 11 个因子未通过 BH-FDR**；
2. **收益预期按 bootstrap 区间理解**：Sharpe 95% CI [0.00, 1.52]，
   对外表述应为"年化 8~9%、Sharpe 0.5~1.0 之间，样本不足以精确估计"；
3. IC 层面可信（NW t≈11），可作为"选股有 alpha"的证据；但**不要用 IC 的 t 去支撑收益预期**；
4. 若未来想用 FDR 做硬筛选，建议把 DEV 窗口拉长（目前 147 周太短）或改用
   Deflated Sharpe / PBO（组合层面）而非单因子 FDR。
