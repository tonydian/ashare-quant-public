# 个股详情模型下拉框瘦身：31 → 1

日期：2026-11-02 ｜ 改动文件：`web/services.py`、`docs/WEB_API.md`、`tests/test_web.py`
｜ 实测服务：`127.0.0.1:8773`

---

## 1. 结论

个股详情页的模型下拉框从 **31 项收到 1 项**（只剩生产主模型 `wf_h10`）。
因为只剩一个选项，前端按既有逻辑自动隐藏了下拉框，页面上不再有"选择模型"这一栏。

不只是删选项：根因是**注册表用黑名单生成**，这次一并改成白名单，
以后跑实验不会再往下拉框里塞条目。

---

## 2. 为什么只留一个

`build/models/` 下有 40 个目录（172MB），旧逻辑排除 9 个内部目录后暴露 31 个。
逐个按"是否通过独立验证"过筛，只有 `wf_h10` 合格：

| 候选 | 关键数字 | 结论 | 依据 |
|---|---|---|---|
| `wf_h10` | 年化 7.11%（毛）/ 7.05%（净），OOS Sharpe 3.68% | **保留** | 生产主模型，23 次 walk-forward refit |
| `wf_h40` | 前向超额 5.88% vs 6.13% | 否决 | 40 日标签。全期略低；2024-26 做到 10.02% 但 2020-21 掉 2.3pp，互相抵消；Top40 样本外 +(-0.5)bps（t=-0.04） |
| `wf_v1` | IC 0.076 | 否决 | 5 日标签早期版本，`wf_h10` 就是它的继任者，同池比较无增量 |
| `wf_h10_fund` | IC 0.085 | 否决 | 37 因子含 4 个基本面，"路线三"实验已否决 |
| `wf_rs10` | 6 因子，refit 仅 1 次 | 否决（**且有陷阱**） | IC 曲线是全期回填而非滚动；当对照项用会得到前视虚高的对比结论 |
| 其余 26 个 | IC 0.058–0.089 | 否决 | `exp_trim_*`（本轮因子池实验产物：T1 6.44%、T2 5.10%、T3 7.82%、W0 5.99%；T3 看似最高，但剔除 2026 后转 −0.28pp、2025 仅 14% 窗口为正）、`wf_h10_{liq,lhb,size,flow,margin,smallvol,nn,m_all2-4}`（单主题微调）、`*_legacy`（存档） |

也就是说不是"懒得清理"，而是**除主模型外没有一个能过独立账户回测 + 样本外不归零**。
留它们在界面上，等于给用户一堆看起来有数、实则未经检验的选项。

## 3. 根因修复：黑名单 → 白名单

旧实现（`_discover_models`）扫 `build/models/*`，再减掉写死的 `MODEL_EXCLUDE`：

```python
for d in sorted(base.iterdir()):        # 字母序
    if d.name in MODEL_EXCLUDE: continue
```

两个毛病：

1. **越跑越多**——每做一次实验（`exp_trim_T1`…）就自动冒进下拉框；
2. **主模型排在第 23 位**——字母序下 `wf_h10` 夹在一堆 `wf_h10_*` 变体中间。

现在：

```python
MODEL_SHOW = {
    "wf_h10": ("左侧主模型", "量价反转+低波，34 因子，10 日标签（默认）", "prod"),
}
```

- 只遍历白名单，**顺序即声明顺序**，主模型天然排第一（默认选中）；
- 磁盘上新目录默认不可见，要上线就在此登记一行，5 秒 TTL 生效、无需重启；
- `kind` 区分 `prod` / `research`，将来加对照模型时前端可分组。

## 4. 顺手修掉一个静默降级 bug

改白名单前先实测了旧行为，发现个股接口是个坑：

```
GET /api/stock/600676?model=exp_trim_T1   →  HTTP 200
{"score": null, "score_rank": null, "factors": [], ...}
```

原因：`_stock_detail_impl` 里 `recommend()` 包在 `try/except Exception: rec=None`，
模型名非法时异常被吞掉，页面会渲染成"有价格、没分数、没因子"的空白态，
用户完全无法判断是自己选错了模型还是数据缺失。

修法：进函数先校验模型名（域外 fast_path 之前），非白名单直接 `ValueError` → HTTP 400。

## 6. 回归测试

`tests/test_web.py` 新增 `test_model_registry_is_whitelist`，锁四件事：

1. 装配结果 ⊆ `MODEL_SHOW`（越权暴露直接红）；
2. 主模型排第一；
3. 磁盘上存在但不在白名单的目录**必须**不出现在列表里；
4. 每项都有 `label` / `desc` / 合法 `kind`。

跑过的模块：

## 7. 以后想加回某个模型

`web/services.py` 加一行即可，不用动画布、不用重启：

```python
MODEL_SHOW = {
    "wf_h10": ("左侧主模型", "...", "prod"),
    "wf_xxx": ("实验对照", "一句话说明它和主模型的差别", "research"),
}
```

前提是先跑通独立账户回测 + 样本外检验——否则加回来只是把噪音放回界面。

磁盘上那 39 个不暴露的目录（合计约 167MB，`build/models` 整体 172MB）**没删**：
`tests/test_audit_rs21.py` 等审计脚本仍要读 `wf_rs10`、`wf_h10_legacy` 做对照，
删了会断链。界面不暴露即可，空间不值得为它冒险。
