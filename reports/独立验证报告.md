## 2. 逐项检查结果

### 2.1 A1 未来函数（代码审查 + 扰动实验）

- **因子**：33 个 base 全部为后向算子（shift/rolling/ema/cumsum），无 `shift(-k)`、无全样本统计。
  扰动 `t0=2022-06-15` 之后全部 OHLCV 后，每个 base 在 `t≤t0` 的因子值**逐位相同**（NaN 位置也相同）；
  t0 之后确实变化（扰动有效）。
- **标签**：`fwd_ret/fwd_open_ret` 只用于评估与训练，未进入因子计算；回测只用 `scores`。
- **walk-forward**：训练窗口 `[r−156, r−2)`，训练集最后标签的卖出日 ≤ refit 日；复合分只由
  `refit ≤ t` 的权重组装；时序平滑只用上一周值。截获每次 refit 实际传入 `fit_weights` 的标签，
  与独立重算逐位一致；把最后一个有效 refit 之后的因子面板替换为随机数重跑，**refit 前 scores
  逐位不变**。
- **回测时序**：t 日收盘生成目标权重 → t+1 开盘执行（`ExecutionEngine.execute`），无 t 日开盘
  使用 t 日信息的路径；regime 均线用 t 日收盘（信号在收盘后生成，**可接受**）。
- **momentum-extra**：`mom{k}`/`mom{k}s{s}` 只用过去价格比；扰动未来价格后历史值逐位不变；
  `build_feature_block` 只做逐行横截面 rank/中性化/zscore，不引入未来信息。

### 2.2 A2 数据层（用原始 npz/csv 独立重算，逐元素一致）

- `alive`（首末有效 bar）、`is_suspended`（alive 但当日无 bar）与原始数据完全一致；上市前/退市后为 NaN。

  （最大相对误差 **1.09e-7**）；日收益与后复权 close 一致；alive 区间内 price/price_open 全部有值。

## 4. 复现性 / 泄漏检测

- **回测复现性**：同输入 `run_backtest` 重跑两次，NAV 与 trades **逐位一致**（allclose 1e-12 且
  `array_equal` 通过）。主回测产物亦可由 `scores + 记录参数` 完整复现。
- **模型复现性**：用 `weekly_top.npz + momentum_extra.npz + 保存的 pool/cfg` 重跑 `walk_forward`，
  scores 与 `wf_h10/composite_score.npz` **逐位一致**；23 次 refit 日期一致。
- **泄漏检测（scores 行内 shuffle）**：
  - 原始：CAGR 7.35%，Sharpe 0.632；
  - shuffle 后：CAGR 1.12%，相对 csi_all 超额 -1.48%，落在随机 40 股组合零分布
    （满仓/无成本，CAGR mean 8.43%、sd 2.66%）内 → z(shuffle) = **-2.64**（不显著为正）；
  - 原始信号 Sharpe 0.632 显著优于随机组合 Sharpe 零分布（mean 0.400、sd 0.105）→ **z=+2.21**；
  - 原始 ≫ shuffle（CAGR 差 +6.2pp）说明信号确实被使用、且不存在“shuffle 后仍有超额”的泄漏通道。
  - 说明：随机等权组合相对 csi_all 天然有小盘 tilt 且满仓无成本，故其 CAGR 高于本策略
    （策略平均目标仓位 66%、成本 1.36%/年）；风险调整后（Sharpe）策略显著更优。
