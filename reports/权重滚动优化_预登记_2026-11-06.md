## 0. 要回答的问题

现役权重 `主 40% / 低换手 30% / ETF 20% / 转债 10%` 是板块腿退役时继承的，
**从未被优化过**。已知：

- 在 1291 点满仓网格里其 Sharpe 排 **932/1291**；
- 转债锁死 ≤10% 时仍有 376 个可行点，最优 Sharpe 是 25/20/45/10（SR 1.165 vs 1.089）；
- **但网格最大值是样本内选择偏差，不能直接采纳。**

本实验问的是：**有没有一个"只用当时可得历史"的权重规则，能在样本外跑赢固定 40/30/20/10？**

### 1.1 成本数字的来源

- 主策略 / 低换手：项目全库假设 40bp 双边滑点，加佣金约 7bp → 单边 ≈ 25bp。
  注意 40bp 本身没有成交数据支撑（`reports/滑点校准工具与代理估计_2026-11-05.md`），
  代理估计指向 15~25bp；这里用 25bp 是**偏保守**。
- 宽基 ETF：价差 1~2bp，冲击极小，取 10bp 单边（已含冲击上界）。
- 可转债：15bp 滑点 + 0.5bp 佣金 = **15.5bp 单边**，与 11-01 审计同一口径。

## 2. 候选方案与 N_trials

| 代码 | 规则 | 计入 trials |
|---|---|---|
| `FIX` | 固定 40/30/20/10 | 否（基线） |
| `INV_VOL` | w ∝ 1/σ（窗口内），再按约束裁剪归一 | 是 |
| `ERC` | 最小化风险贡献离差（`qf/portfolio_erc.py` 同款目标） | 是 |
| `MIN_VAR` | 最小化 wᵀSw | 是 |
| `MAX_SR` | 最大化 (wᵀμ − rf)/√(wᵀSw) | 是 |

**N_trials = 4。** 敏感性分析（窗口 750 / 频率 126 天）只用于检查稳健性，
**不能用来把一个未通过的结论救回来**，也不计入 trials。

## 3. 判据（六条，全过才动生产）

| # | 判据 | 阈值 | 为什么 |
|---|---|---|---|
| H1 | 样本外 Sharpe 提升 | ≥ FIX **+0.05** | 低于这个数在 n≈1100 天里是噪声 |
| H2 | 样本外 MaxDD | 不比 FIX 差超过 **2pp** | 不许用回撤换收益 |
| H3 | 分段一致 | 三段（按 OOS 实际边界切）**≥2/3 段** 的 Sharpe 高于 FIX，且任一段年化不落后 FIX 超过 2pp | 防单段独撑 |
| H4 | 分腿成本下仍成立 | H1 在**分腿成本**与**统一 5bp** 两个口径下都要过 | 防"靠低成本假设取胜" |
| H5 | DSR | 计入 N_trials=4 后 **DSR ≥ 0.95** | 项目铁律 |
| H6 | 不退化 | 平均权重里任一腿 **≥55%** 视为退化，判不通过 | 防优化器把仓位压成单腿 |

**全部通过** → 才改 `scripts/daily_signal.py` 的 `--four` 权重（且改为按季更新的表）。
**任一条不过** → 记录证伪，权重保持 40/30/20/10 不动。

## 4. 已知不覆盖的部分（如实登记）

1. **8 相位不做**。相位只改变主策略腿**内部**的调仓日；要做必须先生成 8 条不同的
   主腿净值曲线（每条都要重跑股票回测），再各自做权重优化。本轮不做，
   因此本结论**不含相位稳健性**，只含窗口/频率稳健性。
2. **不含现金与 regime**。本实验是满仓四腿内部分配；加入 regime 后腿的收益会缩放，
   权重最优解可能变（低波腿在防守态更占优）。这一点在结论里必须写明。
3. **不修正腿之间的相关性漂移**。ERC / min-var 在危机时会把权重推向"近期最稳"的腿，
   这可能是滞后指标；只能靠分段结果观察，不能在方法上消除。

**H5 的判据设计有缺陷**（如实登记，不算事后放宽，属方法论教训）：
DSR 检验的是「扣掉多重检验后 SR>0」，而四个方案的 SR 都远大于 0，因此全部 1.000，
没有区分力。这类「与基线比」的实验应改用「基线差值的 bootstrap 区间」。
