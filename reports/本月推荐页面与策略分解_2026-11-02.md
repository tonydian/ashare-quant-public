# 本月推荐页 + 「按策略看推荐」改造

日期：2026-11-02 ｜ 涉及 `web/services.py`、`web/server.py`、`web/static/{index.html,app.js,style.css}`、
`scripts/daily_signal.py`、`tests/test_monthly_recommend.py`（新增）、`tests/test_combo_{signal,three}.py`

## 一、结论

1. 低换手不再只是「今日清单里的一撮」：新增独立页面 **本月推荐（`#monthly`）**，
   一屏讲清「这个月持哪 10 只、换了哪几只、为什么换、成本多少、历史上怎样」。
2. 今日推荐页回答「能否体现不同策略」：KPI 下方新增 **按策略看推荐** —— 四条腿各一张可点卡片
   （权重 / 标的数 / 预算 / 已投 / 回测年化与 Sharpe），点卡片或上方标签即筛选清单；
   低换手卡片右下角「看本月整月名单 →」直接跳新页。
3. 顺手修了一个真 bug：主策略侧整手取整**向上**取整，39 只整体超预算 2.9%
   （120,000 → 123,523）。改成「先向下取整 + 余额补一手」，现在 119,786 ≤ 120,000，
   页面「已投 > 预算」的黄色告警自然消失。

## 二、为什么值得单开一页

低换手是**月频**策略，名单一次管一个月。塞在今日清单里的问题是：
一屏 49 行混着四条腿，能看见「今天买哪几手」，看不见：

- 这个月到底持什么（10 只，银行 4 只占 42%）；
- 换了什么（换入重庆水务、天新药业；换出招商港口、中铁特货；保留 8 只）；
- 为什么不能清仓重建（年换手 7.1x vs 24x，成本差 13pp）；
- 它的收益结构（毛 13.82% / 净只换 9.84% / 全清全建 0.66%）。

这四件事都是「月度」信息，只有独立页面能讲清楚。而今日清单仍然保留低换手个股
（它们确实是今天要买的），只是不再承担解释职责。

## 五、口径与实现要点

- `GET /api/monthly_recommend` 只读已落盘产物（`lowturn_signal.json` +
  `latest_combo.json.lowturn` + `runs/lowturn/{result,picks}.json` + `nav.parquet`），
  不触发行情加载，服务冷启动也能开。
- 份额口径优先用组合 legs（`sized_by="combo"`），没有组合信号时退回单策略满额（`standalone`，页面标注）。
- `perf.cagr`（只换变动，净）/ `gross_cagr`（零成本）/ `strict_cagr`（每月全清全建）三口径并列展示；
  `cost_drag_pp = (gross − net) × 100`。
- **个股侧年化/Sharpe 必须走 `qf.metrics.performance(nav, rf=现金收益率)`**：
  自算（日历日折年化 + 无 rf）会得到 6.82% / 0.76，与回测页 7.11% / 0.61 打架。
- `turn20_bp` 是基点：15.38bp → `turn20_pct = 0.001538`（前端 `fmtPctU` 再 ×100）。
  第一版写成 `/100`，页面上成了 15.38%，被测试逮住。

## 六、顺手修的真 bug：主策略整手取整超预算

`daily_signal.py` 主策略侧原来是：

```python
sh = int(round(float(r.shares) * scale / LOT) * LOT)   # 四舍五入 → 可以向上
```

39 只合计 123,523，而预算 120,000 —— **超 2.9%**。ETF / 板块 / 低换手三条腿本来就是
`int(x/lot_px)*LOT`（向下），只有主策略这条用了 `round`。改为：

1. 全部 `raw // LOT * LOT` 向下取整；
2. 算剩余额度，按「被取整掉金额最多」的顺序给每只补一手，补到放不下为止。

结果 119,786（差 214 元），资金总额仍严格守恒 300,000。`test_combo_signal.py` /
`test_combo_three.py` 里原本就有「每侧不得超预算」的断言，之前用 `+2000/+3000` 容差把它盖住了，
现在收紧到 `+1`。

顺带修的是这两个测试文件的**mode 假设**：它们写死 50/30/20，而现行 `--four` 是 40/30/20/10，
上轮改权重后 6 项其实一直在失败（只是没人跑）。现在按 `mode` 自适应，并强制检查 lowturn 侧。

  数据都在 `picks.json` + `nav.parquet` 里，再加一个 `?month=` 参数即可。
