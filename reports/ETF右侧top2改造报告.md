## 1. 关键发现：旧版 ETF 回测有同 bar 前视

### 问题

旧版 `backtest()` 的循环：
```python
if pending is not None and t > 0:
    holding = target              # ← 用 close[t] 成交买入
if holding >= 0 and t > 0:
    nav[t] = nav[t-1] * (close[t, holding] / close[t-1, holding])   # ← 却赚了 t-1→t
```

**买入价是 `close[t]`，但收益算的是 `close[t]/close[t-1]` —— 白拿了「决定买入之前」那一天的涨幅。**

### 量化影响

统计 218 笔实际买入：

| 指标 | 值 |
|---|---:|
| 买入当日平均涨幅 | **+1.538%** |
| 中位数 | +1.324% |
| **当日涨幅 > 0 的比例** | **100.0%** |
| 当日涨幅 > 3% 的比例 | 10.6% |

**100% 为正**——因为"突破 55 日新高"的股票当天必然上涨。

每年约 33 笔买入 × 1.538% ≈ 年化虚高 **2.4pp**，
与"旧版 10.57% vs 严格 T+1 top1 8.13%"的差距（2.44pp）**高度吻合**。

### 修复

改为严格 T+1：
```
t 日收盘：根据 sig[t] 决定目标持仓 → 记入 pending
t+1 日收盘：按 close[t+1] ± 滑点成交
收益：只对"t-1 日就已持有"的标的计入 t 日收益
```

**校验通过**：首个信号日 2013-05-28 → 首笔交易 2013-05-29（晚 1 天）✅

## 3. 一个重要的机制发现：为什么 equal 比 fill 好

改造中发现两个仓位机制：

| 机制 | 含义 | Sharpe（top3） |
|---|---|---:|
| **equal**（采用） | 每只固定占 1/max_pos | **0.952** |
| fill | 有几只就占满仓 | 0.806 |

**equal 反而更好**，因为它隐含了一个风控：
- 只有 1 只突破 → 只投 1/2 仓位
- 2 只都突破 → 投满

### 数据佐证：持仓数 vs 次日收益

| 持仓只数 | 天数 | 次日收益均值 | 胜率 |
|---:|---:|---:|---:|
| 0 | 1408 | +0.025% | 57.6% |
| 1 | 133 | +0.015% | 53.4% |
| **2** | 73 | **+0.125%** | 57.5% |
| 3 | 34 | +0.087% | **38.2%** |

**持 2 只时收益最好（+0.125%），持 3 只时胜率暴跌到 38.2%。**

说明：
- **2 只共振是真的强势**；
- **3 只同时突破 = 普涨行情 → 往往是阶段顶部**（拥挤信号）。

**这也是为什么 top2 是甜点，而不是 top4/top5。**

## 7. 诚实的结论

**这次改造的真正价值不是"提升收益"，而是"消除虚高"。**

- 旧版 10.57% 是**含前视的假象**，真实只有 8.13%（top1）；
- 改用 top2 后真实水平 8.61%，**这是可实现的**；
- 组合回撤从 -9.44% 收窄到 -6.42%，**这才是实打实的改善**。

**教训**：这是本项目第三次发现同 bar 前视（板块轮动、研究版 v3、ETF 趋势）。
**规律很清晰：所有"买当下领涨标的"的策略，都极易犯这个错。**
