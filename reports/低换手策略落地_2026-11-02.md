## 二、为什么是「只换变动」

回测（2020-01 ~ 2026-10，82 个月，单边成本 49.3bp）三种执行方式：

| 执行方式 | 年化 | Sharpe | 最大回撤 | 单边年换手 |
|---|---:|---:|---:|---:|
| 毛（不计成本） | **14.03%** | 1.07 | −12.43% | 7.12x |
| **只换变动（净）** | **10.02%** | **0.75** | **−12.70%** | 7.12x |
| 严格全卖全买（净） | **0.54%** | −0.03 | −20.15% | 24x |

相邻月份名单重合 **70.7%**，每月实际只换 3 只左右。按字面「月末清仓 + 次月初全部买回」执行，
每年付掉 `24 × 49.3bp = 11.8%` 的成本，14.03% 的毛利直接被抹平，只剩 0.54%——
**这不是风险收益问题，是执行方式问题**。

「只换变动」的具体动作（`_rebalance`）：

1. 退出名单的 → 开盘全卖；
2. 新进名单的 → 补足到 1/N 等权；
3. 留在名单里的 → **只在偏离目标权重超过 2% 时才调整**。

第 3 条是关键：既维持了「等权」的策略定义，又不为微小的权重漂移付费。

## 五、怎么用

```bash
# 每月月末收盘后跑一次（数据已更新到当天）
python scripts/lowturn_signal.py --capital 300000

# 已有持仓时，额外输出该买/该卖多少
python scripts/lowturn_signal.py --capital 300000 --holdings signals/current_holdings.csv

# 回看历史某天该买什么
python scripts/lowturn_signal.py --asof 2024-06-28
```

`--holdings` 格式与 `daily_signal.py` 一致：两列 `code,shares`，如

```csv
code,shares
601398,3400
601988,4200
```

输出（`signals/`）：

- `lowturn_target.csv` — 目标持仓（代码/名称/行业/换手率/市值/均额/价格/股数/权重）
- `lowturn_orders.csv` — 相对当前持仓的订单，`reason` 取 `initial_build/entry/exit/trim`
- `lowturn_signal.json` — 元数据（目标月份、时点状态、下次动作、回测摘要、名单变化）
- `reports/低换手信号_<日期>.md` — 中文报告，可直接照着下单

**执行节奏**：月末最后一个交易日收盘后跑 → 次日（下月首个交易日）**开盘**调仓。
脚本会自动判断时点：`status=month_end` 表示今天就是月末（可以算下月名单），
`mid_month` 表示本月已建仓、等下次调仓。

回测页「单策略」下新增第 5 张卡 **低换手月度**，参数：

| 参数 | 默认 | 说明 |
|---|---:|---|
| 持仓只数 | 10 | |
| 换手率窗口 | 20 | 交易日 |
| 上市最少交易日 | 250 | 约一年 |

| 每月把权重校准回等权 | 勾选 | 取消后保留仓位完全不动（年化 9.61%，但持仓权重会漂移） |

「扣费后」开关对它是**真双账本**：毛/净是两套独立份额账本，不是按差额补扣的近似
（`cost.note` 会说明）。实测切换：毛 14.03% ↔ 净 10.02%，3.7 秒返回，命中缓存后 0.08 秒。

## 七、必须知道的风险

1. **这不是「低流动性 alpha」，是红利/大盘价值暴露。** 持仓长期是中国银行（82 期里出现 78 次）、
   工商银行、农业银行、中国石油、中国人寿。82 期只出现过 75 只不同股票，
   持仓市值中位按年看在 2,153 ~ 6,334 亿之间摆动（无趋势性下沉），
   本质是「大市值 + 换手清淡」，2026 年出现的天新药业、重庆水务是少数例外。
2. **收益高度集中**：2024 年 +42.1%，2020/2022/2023 三年为 −2.8% / −0.3% / +0.2%。
   六年里只有两年真正赚钱。
3. **成本 49.3bp 是这套策略最大的敌人**。如果券商佣金能降到万 0.5 且滑点控制得好
   （单边 20bp），年化会多出约 4pp。
4. **同样暴露用 ETF 更便宜**：红利 ETF 管理费+跟踪误差约 6bp/年，远低于本策略的
   单边换手 7.12x、双边成本约 7%/年。只有当你想避免 ETF 的成分股调整、
   或需要个股层面的税务/账户安排时，自建组合才有意义。

关键测试项：

- `test_no_lookahead_in_signal`：把信号日之后的换手率全部抹成 NaN，名单不变；
- `test_cost_monotonic`：成本 0 / 49.3 / 98.6bp 三档，年化严格递减且两次差值相差 <35%（防漏扣/重复扣）；
- `test_three_books_ordered`：毛 > 净 > 严格，且净−严格 > 2pp（保证「只换变动」确实省下了成本）；
- `test_picks_are_cheapest`：每期选中的必须是候选池里换手率最低的 10 只（逐期断言 max ≤ min）；
- `test_month_role_last_row_of_data_still_month_end`：数据最后一行恰是月末时，仍要给出下月名单
  （否则每次都会少算一个月，实盘最容易踩的坑）。
