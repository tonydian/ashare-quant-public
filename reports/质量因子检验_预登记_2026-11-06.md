## 1. 为什么做这两个

项目在 2026-11-05 那轮已把 **800 个量价因子 + 15 个基本面因子 + 6 类另类数据**全部筛过。
这里的两个因子是**唯一从没进过任何候选池**的基本面维度：

| 因子 | 中文 | 为什么认为它是真空 |
|---|---|---|
| `earnings_variability` | 盈利波动 | 现有 15 个基本面因子里没有时序波动类；F006 只是「现金流/利润」的当期比率，不含稳定性 |
| `investment_quality` | 投资质量 | 现有因子只有「利润/营收的增长」，没有「资产扩张的合理性」；扩张过猛是价值陷阱的主要成因 |

**动机（说清楚，免得事后编理由）**：现有组合 88% 权重押在「买冷清」（低波 + 低换手 + 价值）。
这类打分的系统性缺陷是**会买到价值陷阱**——便宜是因为公司要变坏。
这两个因子正是针对该缺陷的**解药候选**，不是「再找一个 alpha」。

## 2. 数据来源与口径（重要：这是自建近似，不是 Barra 原值）

**不用 pandadata。** 理由：MCP 通道单次只能回 333 行（byte_limit 先截断），全市场 5,224 只拿不全；
SDK 需独立凭据，本机没有。

改用本地已有数据：

- `fund/*.parquet`：**42 期财报**（2016Q1 ~ 2026Q2），YTD 累计
- `build/pandadata/disclosure_date.parquet`：**44 期真实公告日**（2015Q4 ~ 2026Q3）
- PIT 对齐复用 `qf/fundamentals.py` 的 `FundamentalData`（`avail_mat` + `p_idx`），
  该机制当日盘后披露、次日可用，覆盖率见模块 docstring（半年报 98.6%、三季报 98.1%）

### 2.1 定义

```
roe_ann[p, j]      = M['roe'][p,j] * 4 / quarter[p]              # 年化 YTD ROE
earnings_variability[p, j] = std(roe_ann[p-7 .. p, j])           # 滚动 8 期标准差
                             仅在有效期数 ≥ 6 时计算，否则 NaN

inv_growth[p, j]   = bps[p,j] / bps[p-4,j] - 1                   # 净资产同比扩张率
investment_quality[p, j] = -inv_growth[p, j]                     # 取负：扩张越少分越高
                             仅在 bps[p] 与 bps[p-4] 均 > 0 时计算
```

### 2.2 已知局限（必须写进结论，不得省略）

1. **不是 Barra 原值**。Barra 的 `investment_quality` 用**总资产**扩张，
   本地无总资产字段，只能用**净资产**（`bps`）近似 → 不含负债扩张。
2. **`bps` 受分红污染**：分红会压低 bps，被误判为「低扩张 = 高质量」。
   本地无分红数据可修正，接受该偏差。
3. `earnings_variability` 用 **YTD ROE 年化**后的时序 std，含季节性（Q1 天然低）。
   未做季节调整，属已知噪声来源。
4. 财报期数 42 期，`earnings_variability` 需 8 期历史 → **最早 2018Q1 才有值**。

## 3. 实现方式

在**报告期维度**先算 `P × N` 矩阵，再用 `p_idx[t, j]` 映射到日频 ——
因为 `p_idx` 已按公告日对齐，映射后的日频值天然是 PIT 的。
不改动 `qf/fundamentals.py`，新代码放 `build/exp_quality_factors.py`。

## 4. 样本划分（写死，不得改）

| 段 | 区间 | 用途 |
|---|---|---|
| **DEV** | 2018-01-01 ~ 2021-12-31 | **只用于确认方向**（IC 符号是否符合理论），不用于挑选 |
| **OOS** | 2022-01-01 ~ 2026-11-05 | **唯一的判定样本** |

- 频率：**月频非重叠**（每月最后一个交易日一个观测），避免重叠样本放大 t 值
- 可交易域：`md.eligible` ∩ 该日两因子均 finite
- 未来收益：`close[t+20] / close[t] - 1`（约 1 个月），用后复权价
- IC：横截面 Spearman

## 5. 判据（六条，全过才算因子层通过）

| # | 判据 | 阈值 | 理由 |
|---|---|---|---|
| **H1** | DEV 期 IC 方向符合理论 | `earnings_variability` IC < 0；`investment_quality` IC > 0，且 \|IC\| ≥ 0.02 | 先确认「方向没搞反」，不做显著性要求 |
| **H2** | OOS 期 IC 方向与 DEV 一致且显著 | \|t\| ≥ **2.0** | 主判据。月频 48 个独立样本 |
| **H3** | OOS 内分年度 IC 同向 | ≥ **60%** 的年份同向 | 防单一年份支撑 |
| **H4** | 与生产分数正交 | 与 `wf_h10` 分数横截面秩相关 \|ρ\| < **0.40** | HVRP 的教训：相关 −0.479 则信息已被吃掉 |
| **H5** | 与现有基本面因子不重复 | 与 15 个因子的最高相关 < **0.70** | 防重复造轮子 |
| **H6** | 分层单调 | 五分组 Q1→Q5 单调性 \|ρ\| ≥ 0.7，或 Q5−Q1 spread 方向正确且 \|t\| ≥ 1.5 | 防「只有极端组有效」 |

**N_trials = 2**（两个因子）。若中途增加变体（如改用增量 ROE 版本），必须在此追加并更新 N_trials，
不得悄悄多试。

## 6. 边界（什么情况下我不许动生产）

- **任一判据不过 → 证伪，记录，`qf/` 与 `scripts/` 一行代码不改。**
- **因子层通过 ≠ 可以上线**。通过只代表「允许进组合层」，
  而组合层实验**必须配 `build/placebo.py` 的同比例随机剔除对照组**
  （项目铁律：加过滤会自动白拿「持仓变少 → 仓位变低」的降杠杆红利）。
- 即使因子层 + 组合层都通过，仍需 N_trials 累计 DSR 与三段一致性，才谈改生产。

### 7.4 最终判定

**不采纳，生产代码一行未改。** 详见 `reports/质量因子检验_2026-11-06.md`。
