# 风格归因（Style Attribution）

> 目的：回答「收益到底赚在哪」——是市场 beta、风格暴露（大小盘/估值/动量/波动/换手）、
> 行业配置，还是选股残差（alpha）。实现见 `qf/attribution.py`，入口
> `scripts/style_attribution.py`。

## 1. 为什么不用聚宽的 `AttributionAnalysis`

`JoinQuant/jqfactor_analyzer` 的归因模块依赖聚宽算好的 Barra 风格收益
（`get_factor_style_returns`）和指数成分暴露（`get_index_style_exposure`），
且依赖 `jqdatasdk` 账号与流量、`fastcache`（无 3.13 wheel）。本项目所有数据在本地
parquet 面板里，与其受制于外部服务，不如用自己的面板估一套可控 PIT 的风格模型。
本模块只依赖 numpy / pandas，无新增第三方依赖。

## 2. 方法

对每个调仓期 `[t1, t2)`，取 `md.eligible[t1]` 股票池，做横截面加权最小二乘：

```
r_i(t1→t2) = c + Σ_k coef_k · Z_ik + u_i
```

* `Z`：风格暴露的横截面 z-score；行业哑变量保持 0/1 原值（标准化会破坏「行业收益」含义）。
* 回归权重：`√总市值`（Barra 惯例）。
* 风格定义（全部 PIT，只用 t1 及之前的行情/财报）：

| 风格 | 定义 | 方向 |
| --- | --- | --- |
| SIZE | `ln(总市值)` | 正 = 偏大盘 |
| VALUE | `0.5·z(TTM盈利收益率) + 0.5·z(账面市值比)` | 正 = 偏低估 |
| MOM | 60 日动量，跳过最近 5 日 | 正 = 偏强势 |
| VOL | 60 日日收益标准差 | 正 = 偏高波动 |
| LIQ | 20 日平均成交额 / 总市值 | 正 = 偏高换手 |

* 估值与盈利数据取自 `qf.fundamentals.FundamentalData`（真实公告日 PIT 口径）。

组合贡献：

```
E_k = Σ_i w_i · Z_ik            （w 为 t1 实际持仓权重）
贡献_k = E_k · coef_k            （必须用标准化系数，混用原始系数会破坏恒等式）
MARKET = (Σ w_in) · 市值加权行业组合收益
INDUSTRY = Σ_i w_i · (r_行业(i) − 市值加权行业组合收益)
SPECIFIC = Σ_i w_i · u_i
CASH = (1 − Σ w_i) · 现金套件区间收益（国债指数，与回测口径一致）
UNEXPLAINED = R_实际 − (以上各项之和)
```

**账目闭合自检**：`R_est − Σ(分量)` 记在 `IDENTITY_GAP` 列，正常应 < 1e-2
（残差来自落在未建模小行业里的持仓）。

## 3. 用法

```bash
# 默认读取 build/runs/main（主回测），输出到 build/attr
python scripts/style_attribution.py

# 指定回测与输出目录
python scripts/style_attribution.py --run build/runs/main_rebal10 --out build/attr/rebal10

# 只跑某段区间
python scripts/style_attribution.py --start 2022-01-01 --end 2025-12-31
```

产出：

| 文件 | 内容 |
| --- | --- |
| `style_exposures.csv` | 逐期组合暴露 `E_*` / 基准暴露 `B_*` / 仓位 / 持仓数 |
| `style_contrib.csv` | 逐期贡献 + `R_actual` / `R_est` / `IDENTITY_GAP` |
| `industry_exposure.csv` | 逐期各行业权重 |
| `summary.csv` / `summary_open.csv` | 两种收益口径下的年化贡献汇总 |
| `STYLE_ATTRIBUTION.md` | 可读报告（表格 + 结论 + 限制） |
| `contrib_cum.png` | 累积贡献曲线 + 平均暴露对比 |

## 4. 怎么读

1. **先看账目闭合**：`IDENTITY_GAP` 大说明有持仓落在建模范围外，结果不可信。
2. **再看 SPECIFIC 是否为正且显著**：`t > 1.5~2` 才谈得上「选股 alpha」；
   为负说明选股在行业与风格内部没有超额。
3. **风格合计 vs SPECIFIC**：风格合计更大 → 收益建立在暴露上，风格反转会回吐。
4. **看风格暴露的稳定性**：报告中「组合 vs 基准」暴露差，`SIZE` 差 -0.54 表示
   显著小于市值加权基准（偏中小盘），这类暴露在 2017、2024 初的微盘杀跌中会集中受伤。
5. **UNEXPLAINED 为负且约 -0.5%~-1%/yr 是正常的**（成本 + 整手 + 执行时点），
   若出现 ±3% 以上，先查是不是回测口径或持仓快照对不上。

## 5. 已知限制

1. 收益用后复权收盘 `t1→t2`，与「t 收盘决策 / t+1 开盘执行」有一日错位；
   报告第 4 节给出 `open`（t1+1→t2+1）口径对照，两者差异即执行时点影响。
2. 基准暴露为股票池内总市值加权代理，非指数真实成分权重。
3. 无 Barra 官方风格（如非线性规模、beta、残差波动），是本项目自己估的 5 风格，
   与商业风险模型不可直接对比。
4. 因子收益为样本内横截面估计，含估计误差；41 期样本下 t 值的统计功效有限。
5. 不做风格中性再平衡，不能据此直接构造「风格中性组合」。

## 6. 首次运行结果（2026-10-31，`build/runs/main`）

样本 2020-01-23 ~ 2026-10-30，41 期 / 6.77 年，实际复利 56.70%（年化 7.11%）：

| 分量 | 年化 | t |
| --- | --- | --- |
| MARKET | +5.10% | 1.08 |
| SIZE | -1.15% | -3.60 |
| LIQ | +1.98% | +4.32 |
| INDUSTRY | +1.15% | 1.27 |
| SPECIFIC | -1.04% | -0.81 |
| CASH | +1.87% | +6.72 |
| UNEXPLAINED | -0.61% | -1.74 |

解读：收益主要来自市场 beta（含 55% 平均仓位的择时）+ 现金套件利息 + 低换手偏好，
**选股残差为负**，说明当前主模型的超额更多是「暴露与配置」而非「行业内部选股」。
SIZE 贡献 -1.15% 且 t=-3.60，是最稳定的一项负贡献（组合虽小于市值加权基准，
但相对等权股票池偏大，而小盘长期占优）。

### 敏感性：加不加行业因子

`--no-industry` 去掉行业哑变量后（同一批期数）：

| 口径 | SPECIFIC | INDUSTRY | MARKET |
| --- | --- | --- | --- |
| 含行业因子 | -1.04%（t=-0.81） | +1.15%（t=1.27） | +5.10% |
| 不含行业因子 | +1.15%（t=0.71） | — | +5.08% |

两者相加恰好互换 → **原来的「选股超额」几乎全部是行业配置**（相对市值加权行业权重的
超配），行业内部的个股选择没有可辨识 alpha。这是本模块最有信息量的一次输出：
在没有行业因子时看 SPECIFIC 会高估选股能力。
