# Alpha191：国泰君安短周期价量因子库

> 实现：`qf/alpha_ops.py`（算子）、`qf/alpha191.py`（公式表）
> 扫描：`scripts/scan_alpha191.py`  测试：`tests/test_alpha191.py`
> 数据源公式：聚宽 Alphas191 数据字典（`jqdatasdk.alpha191` docstring）

## 1. 这是什么

国泰君安证券 2017 年研究报告《基于短周期价量特征的多因子选股体系》给出的 191 个
**日频量价因子**。与 WorldQuant Alpha101 的区别：

| | Alpha101（2015） | Alpha191（2017） |
|---|---|---|
| 出处 | WorldQuant | 国泰君安金工 |
| 核心算子 | `rank` / `delta` / `corr`（截面为主） | `SMA(x,n,m)` 递归平滑、`TSRANK`、`DECAYLINEAR`（时序为主） |
| 设计场景 | 日频截面套利 | A 股短周期价量，信号半衰期 ~1 周 |
| 数据依赖 | OHLCV | OHLCV + **VWAP** + 少量基准指数 |

因子覆盖面（按构造要素看）：量价相关（`CORR(RANK(VOL),RANK(VWAP))`）、
日内位置/影线（CTR、RSV、KDJ 变体）、均线偏离（`MEAN/SMA/DECAY`）、
波动与振幅（`STD(HIGH-LOW)`）、量能变化（`VOL/MEAN(VOL,20)`）、
趋势强度（`TSRANK`、`REGBETA`）。

## 2. 数据口径（决定了能不能直接用）

原始语料是"日频价量"，但落到本项目的数据面板上有四个必须显式选择的点：

**① VWAP 需要重建，而且必须是 PIT 口径。** 数据源里 `open/high/low/close` 是**后复权**，
`amount/volume` 是**不复权**口径，两者相差一个逐股分段恒定的复权因子 `k`：

```
VWAP = (amount / volume) × k,   k ≈ median( 典型价_后复权 / (amount/volume) )
```

`k` 只在除权日跳变，所以取它的**滚动中位数**（默认过去 61 个交易日）：

- `method="rolling"`（默认）：严格 PIT，任何时点只用历史数据，约 10 秒；
- `method="segment"`：先按 2% 跳变切段、取段内中位数。**快，但段内中位数含段后半段
  信息 → 前视**。实测同一份代码，`alpha_013` 的 IC 会从 **+0.029 虚高到 +0.099**
  （`alpha_124` 从 -0.003 变成 +0.016），足以把排名完全打乱。

校验：`VWAP/CLOSE` 中位数 1.0000，1%/99% 分位 0.958/1.042；
`(VWAP-典型价)/典型价` 的 5%/95% 分位为 ∓1.6%，符合"均价围绕典型价小幅波动"的先验。
不重建的话，凡是含 `VWAP` 的 30 多个因子会因为复权因子错位（累计分红可达数倍）彻底失效。

**② 复权与停牌。** `close` 已是后复权 + 停牌前向填充，`volume` 停牌日为 0。
成交量/额缩放为「百万股 / 亿元」只为数值稳定，横截面排名不变。

**③ `RANK` 是横截面百分位秩。** 实现为居中到 `[-0.5, 0.5]` 的百分位秩；
与 JQ 的 `RANK` 相差一个逐行的仿射变换，对"因子排序"无影响。

**④ 满窗口径。** 所有滚动算子要求窗口内无缺失，否则 NaN
（等价 `pandas.rolling(w, min_periods=w)`），上市不足窗口的股票自然为空。

**⑤ `SMA(x,n,m)` 的初值与预热。** `y_t = (m/n)·x_t + (1-m/n)·y_{t-1}`。
朴素实现从 0 起步，上市后前 `~3n` 个交易日会有 `(1-m/n)^t` 的预热偏差
（实测 n=20 时第 60 天仍偏 4.4%）。本实现先做前向/后向填充，并把 `y_{-1}`
设为每列首个有效值，与 `pandas.ewm(alpha=m/n, adjust=False)` 逐格一致。

**⑥ 基础面板用 float32 存储。** 2440×5281 的面板，float64 一份就是 103MB，
20 个基础面板会吃掉 2GB；float32 存储 + 算子内部升 float64，
量化误差约 1e-7，对排序型指标无影响（测试里放开了 1e-5 容差）。

## 3. 原文缺陷与处理

聚宽文档里的公式有一批录入错误。逐条处理如下（**这部分不做取舍就没法复现**）：

| 因子 | 原文 | 处理 |
|---|---|---|
| 005 | `YSRANK(HIGH,5)` | 按 `TSRANK` |
| 008 | `((HIGH+LOW)/2)_0.2` | 下划线是乘号乱码 → `*0.2` |
| 009 | `.../*(HIGH-LOW)/VOLUME,7，2` | `/*` 与全角逗号 → `((H+L)/2-(DH1+DL1)/2)*(H-L)/VOL` |
| 011/060 | `./(HIGH-LOW).*VOLUME` | MATLAB 逐元素写法 → 普通除/乘 |
| 023 | `STD(CLOSE:20)` | 冒号 → 逗号 |
| 028 | 第二项 `TSMAX(LOW,9)` | 同一因子里前面已用 `TSMIN(LOW,9)`，统一按 `TSMIN` |
| 031 | `LOSE-MEAN(...)` | `LOSE` → `CLOSE` |
| 052/110 | `...-L),26)` | `L` → `LOW` |
| 069 | `(...)？0:(...)` | 全角问号 |
| 078 | `MA((H+L+C)/3,12)` | `MA` → `MEAN` |
| 091 | `RANK(...)_RANK(...)` | 下划线 → 乘号 |
| 131 | `DELAT(VWAP,1)` | → `DELTA` |
| 159 | `MAX(HGIH, ...)` | → `HIGH` |
| 166 | `(20-2)(SUM(...))` | 缺乘号 |
| 190 | 原文给出"原公式 / 修改后公式" | 采用修改后版本 |

**无法实现（11 个，191 − 180）**，逐条原因：

| 因子 | 原因 |
|---|---|
| 030 | 需 Fama-French 三因子（MKT/SMB/HML）日频序列，本项目未接入 |
| 054 | `STD(ABS(CLOSE-OPEN))` 缺窗口参数，口径不唯一 |
| 075 | 只依赖基准指数，横截面恒等于常数 |
| 101 / 123 | 聚宽原文在公式中途被截断（以 `\` 结尾），缺失部分决定因子方向 |
| 143 | 含递归变量 `SELF`（引用前一日自身值），原文未给初值 |
| 149 | 需按基准指数涨跌过滤样本后做 252 日回归，口径不唯一 |
| 165 / 183 | 使用 `SUMAC`（累计求和），聚宽自己标注「尚未实现」 |
| 181 | 基准指数参与 `^2`/`^3` 幂次，原文口径可疑 |
| 182 | 需基准指数的日线涨跌方向（本项目基准只存收盘指数，缺开盘），且横截面只有 0/0.5/1 三档 |

> 128 的原文也截断了，但缺失的一半与可见的一半严格对称（涨/跌方向互换），
> 补全唯一，因此保留；101/123 缺失的是"与右侧另一个因子比大小"的部分，
> 换个右侧因子方向就反了，故不复现。

## 4. 算子语义

| 算子 | 语义 | 实现要点 |
|---|---|---|
| `DELAY(A,n)` | n 日前值 | 行位移，前端补 NaN |
| `DELTA(A,n)` | `A_t - A_{t-n}` | |
| `SUM/MEAN/STD(A,n)` | 滚动和/均值/标准差 | `cumsum` 差分，总体口径（÷n） |
| `CORR/COV(A,B,n)` | 滚动相关/协方差 | `cumsum`；**按列分块**（5 个中间数组否则超 1GB） |
| `TSMAX/TSMIN(A,n)` | 滚动极值 | 逐 lag `np.maximum` 原地累加 |
| `TSRANK(A,n)` | 末值在窗口内的分位（0~1） | 逐 lag 计数 |
| `LOWDAY/HIGHDAY(A,n)` | 极值距今天数（0=当天） | 逐 lag 追踪 |
| `DECAYLINEAR(A,n)` | 权重 n..1 归一化加权 | 逐 lag 加权累加 |
| `WMA(A,n)` | 权重 `0.9^i`（研报口径） | 同上 |
| `SMA(A,n,m)` | 系数 `m/n` 的递归平滑 | `scipy.signal.lfilter` + 初值修正 |
| `RANK(A)` | 横截面百分位秩 | `argsort` + 居中 |
| `COUNT(cond,n)` / `SUMIF` | 窗口内条件为真的**天数** / 条件求和 | 布尔→0/1 后滚动求和（不能数"非空个数"） |
| `REGBETA(y,SEQUENCE(n))` | y 对时间序号的滚动斜率 | 闭式解（`Σi·y_i` 逐 lag 加权） |
| `PROD(A,n)` | 窗口连乘 | 对数求和再取指数 |

## 5. 验证

`tests/test_alpha191.py` 共 29 项，全部与 **pandas 独立实现**逐格比对：

- 滚动和/均值/标准差/最大最小/相关系数 → `pandas.rolling`
- `TSRANK` → 手算分位（窗口内小于当日值的个数 / n）
- `DECAYLINEAR` / `WMA` → 手算权重
- `SMA(n,m)` → `pandas.ewm(alpha=m/n, adjust=False)`
- `SEQUENCE` 斜率、`TSARGMIN/MAX`、`SUMIF` → 构造用例
- **端到端**：用 pandas 独立实现 `alpha_001`（`CORR(RANK(DELTA(LOG(VOL))),RANK((C-O)/O))`），与公式表实现逐格一致（rtol 1e-6）
- `alpha_014`（`CLOSE-DELAY(CLOSE,5)`）与直接位移比对

## 6. 实测结果

口径与主模型完全一致：477 个周频期（2017-01-03 ~ 2026-10-27），
标签 `md.fwd_open_ret(5)`（t+1 开盘买入、持有 5 日），掩码 `md.eligible`。
逐因子明细见 `build/alpha191/metrics.csv`，自动报告见 `build/alpha191/scan.md`。

### 6.1 整体：比现有因子库弱一档

| | Alpha191（180 个） | 现有因子库（200 个） |
|---|---|---|
| \|IC\| 中位数 | **0.0247** | 0.0330 |
| \|IC\| 的 90 分位 | 0.0432 | 0.0608 |
| \|IC\| 最大值 | 0.0765 | 0.0731 |
| \|IC\| ≥ 0.04 的占比 | 12%（22 个） | 28%（57 个） |
| \|t\| ≥ 2 的占比 | 86% | 94% |
| Top20% 周换手（中位） | 0.61 | 0.64 |

即：**中位数低 25%、头部数量只有四成，但换手一样高**。最好的单个因子
（`alpha_159`，IC −0.0765）略高于现有库最好的一个（0.0731），但它是"反向"
的价格位置因子，而且 6 个年度里 5 年在 −0.05 ~ −0.10 之间，非常稳定。

### 6.2 三个"名不副实"的证据

**① 号称短周期，实测是慢变量。** 87%（156/180）的因子在 20 日标签上的 |IC|
**大于** 5 日标签上的 |IC|，只有 16 个（9%）呈现"1 日 > 5 日 > 20 日"的正常衰减：

| 因子 | IC(1d) | IC(5d) | IC(20d) | 判断 |
|---|---|---|---|---|
| alpha_159 | −0.045 | −0.077 | −0.100 | 越拉越长越准 → 状态变量 |
| alpha_070 | −0.036 | −0.065 | −0.091 | 同上（成交额波动率） |
| alpha_088 | −0.032 | −0.049 | −0.066 | 同上 |
| alpha_002（CTR 1 日变化） | +0.019 | +0.017 | +0.012 | 真短周期，但很弱 |

也就是说，这批因子里**日内变化类成分几乎不提供预测力**，真正在起作用的是
"价格/成交额/趋势位置"这类持续数周的状态。这和"用于日频交易"的定位相反，
与网络上"Alpha191 月度调仓全军覆没"的经验观察一致。

**② 一批因子不是尺度无关的。** 前 30 名里有 11 个与 `log 市值 / log 股价 /
log 20 日均额` 的秩相关 \|ρ\| ≥ 0.8：

| 因子 | 公式 | 与"20 日均额"的 \|ρ\| | 实质 |
|---|---|---|---|
| alpha_132 | `MEAN(AMOUNT,20)` | 1.00 | 成交额水平 = 规模 |
| alpha_095 | `STD(AMOUNT,20)` | 0.98 | 规模 |
| alpha_070 | `STD(AMOUNT,6)` | 0.94 | 规模 |
| alpha_167 | 12 日上涨幅度和 | 0.94（与股价） | 价格水平 |
| alpha_042 | `-RANK(STD(HIGH,10))*CORR(HIGH,VOL,10)` | 0.91（与股价） | 价格水平 |

这些因子在 IC 表上排前面，抓的是 **A 股的低价股/小市值溢价**，不是新的选股信号。

**③ 与现有因子库高度重叠。** 对前 30 名做两级正交化（逐周频行、横截面秩空间
最小二乘，见 `scripts/scan_alpha191_incremental.py`）：

| 处理 | \|IC\| ≥ 0.03 | \|IC\| ≥ 0.02 |
|---|---|---|
| 原始 | 23 / 30 | 30 / 30 |
| 剔除 规模+股价+成交额 后 | 23 / 30 | 26 / 30 |
| 再剔除现有库最强的 30 个因子 | **0 / 30** | **2 / 30** |

也就是说：**扣掉你现有 200 因子库里已经有的信息之后，Alpha191 最好的一批
只剩 IC ≈ 0.02**（`alpha_046` +0.021、`alpha_132` −0.021），
不到现有库中位因子（0.033）的三分之二。

### 6.3 相关性结构

以 \|Spearman ρ\| ≥ 0.7 判"同一信号"，180 个因子聚成 **107 个簇**，最大簇 18 个
（代表 `alpha_088`，一类"最高价与成交量的短期背离"）。即 191 条公式的实际
自由度大约只有 107 —— 冗余主要来自同一族公式的不同窗口/不同平滑方式。

### 6.4 顺手修正的一个前视坑（值得单独记一笔）

第一版用"段内中位数"估计 VWAP 的复权因子（见 §2①），`alpha_013` 的 IC 高达
**+0.0987**、t = 26，看起来是"全库第一、碾压现有库"。改成严格 PIT 的滚动中位数后：

| 因子 | 段内中位数（有前视） | 滚动中位数（PIT） |
|---|---|---|
| alpha_013 | +0.0987 | **+0.0286** |
| alpha_124 | +0.0164 | −0.0028 |
| alpha_026 / alpha_090 | +0.0288 / +0.0367 | +0.0284 / +0.0369 |

凡是把 VWAP 和"同一天附近的量"做比值的因子（026、090）不受影响，
凡是直接用 VWAP **水平**的因子（013、124）全部被污染。教训：**代理变量的估计
一旦用到全样本，就会把未来信息灌进因子**，而且灌进去的量足以把排名完全打乱。

## 7. 结论

1. **不值得整库引入。** 180 个可复现因子里，没有一个能在"剔除风格 + 剔除现有库"
   之后提供 ≥ 0.02 的 IC；中位水平还比现有库低 25%。
2. **它不是短周期因子库。** 87% 的因子在 20 日上更强，日内变化类成分贡献很小；
   如果你的调仓周期是 5~10 日，这批因子的"短周期"卖点并不成立。
3. **风格污染严重。** 前 30 名里 11 个是价格/规模代理；直接扔进模型会强化
   小市值、低价暴露（这正是 `docs/STYLE_ATTRIBUTION.md` 里 SIZE 年化 −1.15% 的那一类）。
4. **值得单独试的只有 5 个**（正交后仍有余量、换手不算高）：

| 因子 | 公式要点 | 原始 IC | 剔风格后 | 再剔现有库后 | 周换手 |
|---|---|---|---|---|---|
| alpha_046 | 4 条均线均值 / 收盘价 | +0.040 | +0.044 | **+0.021** | 0.58 |
| alpha_062 | `-CORR(HIGH, RANK(VOLUME), 5)` | +0.040 | +0.032 | **+0.019** | 0.75 |
| alpha_090 | `-RANK(CORR(RANK(VWAP),RANK(VOL),5))` | +0.037 | +0.027 | **+0.015** | 0.76 |
| alpha_099 | `-RANK(COV(RANK(CLOSE),RANK(VOL),5))` | +0.044 | +0.034 | **+0.015** | 0.75 |
| alpha_083 | `-RANK(COV(RANK(HIGH),RANK(VOL),5))` | +0.046 | +0.033 | **+0.013** | 0.73 |

   （062/090/099/083 本质是同一件事：**价量相关性/协方差的负向**。留一个就够，
   推荐 `alpha_062`，因为不需要 VWAP、换手同档、IC 最高。）

## 8. 怎么用

```python
from qf import alpha191 as A
from qf import evaluate as qfe

rows = qfe.weekly_rows(md)
panels = A.compute_panel(md, [46, 62], rows=rows)   # {46: (477, N), 62: (477, N)}
```

- 单因子计算 1~15 秒（视窗口长度），全量 180 个约 20 分钟。
- 因子方向以 `metrics.csv` 里 `ic_5d` 的符号为准，负 IC 的因子要做反向处理。
- 这批因子**没有做行业/市值中性化**，直接用会被风格吃掉；用之前至少先对
  `log 市值 + 行业哑变量` 做横截面回归取残差（`qf/attribution.py` 里有现成的
  WLS + 行业设计矩阵实现可以复用）。
- 想要完整的公式级复现：`python scripts/scan_alpha191.py`（约 20 分钟），
  再做增量检验 `python scripts/scan_alpha191_incremental.py --top 30 --n-base 30`。
