# Web UI 使用说明

> 本地单页量化看板：看盘 / 个股推荐 / 回测 / 个股详情 / 数据抓取 / 因子库 / 报告。
> 技术栈：Python 标准库 `ThreadingHTTPServer`（无第三方 web 依赖）+ 原生 HTML/CSS/JS（无 CDN）
> + matplotlib 服务端出图（中文字体 Microsoft YaHei）。接口契约见 `docs/WEB_API.md`。

## 启动

```powershell
$py = 'D:\wkf\getrich\.venv\Scripts\python.exe'
cd D:\wkf\getrich\ashare_quant

# 默认 127.0.0.1:8765，优先使用增量数据 was_stock_data_ext（到最新交易日）
& $py scripts/web_server.py

# 与回测报告同口径（原始数据 2026-10-14）
& $py scripts/web_server.py --data orig

# 换端口 / 不预热推荐（启动更快，首次点推荐慢 ~20s）
& $py scripts/web_server.py --port 8766 --no-prewarm
```

打开浏览器访问 **http://127.0.0.1:8765/**。

启动后后台加载行情（约 15~20s），`/api/meta` 的 `server.loaded=true` 表示就绪；
页面顶栏会显示加载状态并自动重试（加载完成后自动刷新当前页）。

## 实现要点

- **数据服务**（`web/services.py`）：启动时加载 `MarketData` + `FactorInputs` + saved 模型；
  推荐计算复用 `qf.portfolio.build_target` + `daily_signal.market_regime`，与 CLI 信号口径一致；
  个股因子贡献 = 池内因子 live 特征 × 最新 walk-forward 权重。
- **回测**（后台线程 + 任务轮询）：saved 模型打分较长（原始数据 2428 行），增量数据多出的行补 NaN；
  保持「打分只到模型训练窗口、NAV 计到最新交易日」。结果落内存，可随时重看图。
- **数据更新**：调用 `scripts/update_data.py` 子进程（标准库 urllib 抓腾讯行情，无第三方依赖），
  日志流式显示；完成后自动清缓存并重载（`/api/meta` 的 `data.last_date` 更新）。
- **图表**：matplotlib 每次新建 `Figure` + `FigureCanvasAgg`（线程安全），PNG 内存缓存；
  深色主题、A 股红涨绿跌、中文正常（msyh.ttc）。
- **安全**：默认只绑定 127.0.0.1；静态文件服务限制在 static/reports/signals 目录内（防目录穿越）。

## 低换手月度策略（2026-11-02 新增）

回测页「单策略」第 5 张卡。规则：上月末按 20 日均换手率（成交额/总市值）升序取最低 10 只，

  输出 `signals/lowturn_target.csv` / `lowturn_orders.csv` / `lowturn_signal.json` 与中文报告；

- 右侧分组卡片四侧常驻：某侧无标的时显示「预算 X%、0 个标的」，不再凭空跳过，
  配合「现金」卡片的空仓说明能对上账；
- 空仓说明会额外提示：①低换手侧的目标月份与执行时点（月末出下月名单 / 月中已持有）；
  ②ETF、板块两侧的信号日期若早于行情日期，会明确写「信号基于 X，比行情 Y 晚，可能漏掉最新突破」；
- 导出 CSV（`/api/today_export`）包含低换手个股，类别列写「低换手个股」。
- 权重依据见 `reports/回测合理性审计与今日推荐接入低换手_2026-11-02.md` 第八节：
  换权重不是为了全期多 0.36pp，而是原三策略 2023-2026 只有 5.65%/Sharpe 0.495，
  加低换手后 8.36%/0.861。
- **这套权重不再重估**（`reports/四侧权重样本外检验_2026-11-02.md`）。三条理由：
  ① 五个区间的网格最优组合五个不同答案、四个在角落（全押某一条腿），最优解不稳定；
  ② 每年按过去 3 年最优重选权重，2023-2026 只有 5.94%，比不动的 8.39% 低 2.44pp，
     且"优化得越少越好"（纯等权 7.64% > 收缩 30% 优化 7.16% > 纯优化 5.94%）；
  ③ 剔除 2024 一年后所有候选权重差距消失（6.16%–6.88%）。
  **容忍带（全期口径）**：主 35–45 / 低换手 25–35 / 宽基 20–30 / 板块 5–15；
  只有越界且原因是策略机制失效时才调，**禁止用最近 3 年绩效重估权重**。

## 本月推荐页（2026-11-02 新增）

导航「决策」组第二项，`#monthly`。为什么单独开一页：低换手是**月频**策略，
名单一次管一个月，混在「今日清单」里只能看到「今天要买哪几手」，
看不见「这个月持什么、换了什么、为什么换」。

页面结构（自上而下）：

1. **KPI**：本月标的 / 本侧预算（权重 30% · 本金 30 万）/ 已投与现金 / 回测年化与 Sharpe；
2. **本月名单**：10 只，按换手率升序。列 = 序号·名称·代码·行业·20 日换手·市值·金额·股数·状态（新进/保留）。
   表头右侧标注「按组合 30% 预算切分 · 信号日 · 下次动作」；
3. **本期换仓**：换入 / 换出各几只（带名称）+ 保留几只，底部提醒「不要清仓重建」；
4. **行业分布**：条形 + 占比，银行常年第一（本月 42%），这是这策略的真实风险来源；
5. **净值与近 12 个月**：`nav_real`（只换变动、含成本）最近 500 日归一曲线 + 12 个月涨跌方块（红涨绿跌）；
6. **三种交易方式**：只换变动（执行）/ 零成本（毛）/ 每月全清全建，同一选股规则只改「怎么换」，
   直观看到成本吃掉 3.97pp 与 9.19pp 的差别；
7. **分年度与基准**：净收益逐年 + 中证全指 / 全A等权 / **中证红利ETF**（后复权含股息）对比。
   红利那一行是 2026-11-02 加的**必看项**：低换手本质是红利组合，只跟全指比会虚增 8pp 超额。
   同区间低换手 10.02% vs 红利 10.06% —— 页面会直接看到「打平」；
8. **策略说明与局限**：换手率口径（成交额/总市值）、过滤条件、为什么不做流动性下限、
   为什么只换变动、本质是红利/低波替代。

今日推荐页的变化：

- KPI 下方新增「**按策略看推荐**」卡片：四条腿各一张可点卡片，显示权重、标的数、预算、已投、年化/Sharpe；
  点卡片即筛选下方清单，低换手卡片右下有「看本月整月名单 →」直接跳本月推荐页；
- 「今日操作清单」标题右侧改为**筛选标签**（全部 49 / 主策略 39 / 低换手月度 10 / 宽基 ETF / 板块 ETF），
  选中态高亮；某侧 0 标的时点击会提示「这一侧今日无标的（预算进入现金，或本月无变动）」；
- 右侧「按策略分组」卡片更名为「**预算与剩余**」，另外两张保留（现金、空仓说明）。

## 已知限制

- 盘中实时行情未接入（看盘/推荐基于最近一个完整交易日收盘数据）；如需盘中快照，可在
  `services.py` 增加 akshare `stock_zh_a_spot_em` 接口（注意交易时段限频）。
- 回测为单机串行（一次一个），参数组合扫描请用 `scripts/scan_config.py`；
  回测结果存内存，刷新页面需重跑。
- 推荐页默认从零建仓；若已有持仓，请用 CLI `scripts/daily_signal.py --holdings current_holdings.csv`
  生成换仓订单（Web 端后续可扩展持仓上传）。
- 候选榜"本地搜索"只过滤已加载的前 60 条，不额外请求。
- 页面仅供研究与个人使用，不构成投资建议。
